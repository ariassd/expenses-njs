# Expenses micro service

This is an example of one micro service using nodejs + postgresql



## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Configuration (.env)

```txt

DB_HOST=postgresql://[USER]:[PASSWORD]@localhost:5432/[DB_NAME]


```
